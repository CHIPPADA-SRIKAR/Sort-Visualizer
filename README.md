# Sort Visualizer

A web project that visualizes sorting algorithms using HTML, CSS, and JavaScript.

## What it does

- Generates a random array of bars
- Lets the user select a sorting algorithm
- Animates the sorting process on screen
- Shows comparisons, array accesses, and time complexity

## Technologies used

- HTML for page layout
- CSS for styling and theme
- JavaScript for logic, animation, and sorting

## Files

- `index.html` — main page structure
- `style.css` — visual styles and theme
- `JavaScript_files/sorting.js` — main controller, array generation, and UI logic
- `JavaScript_files/*.js` — individual sorting algorithm implementations

## How to use

1. Open `index.html` in a browser.
2. Choose an algorithm from the dropdown.
3. Adjust array size and speed.
4. Click `Generate Array` to create a new array.
5. Click `Start Sorting` to run the animation.

## Notes

- It is a visualization demo for learning sorting algorithms.
